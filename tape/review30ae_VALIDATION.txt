Important validation-environment note
-------------------------------------
This build container does not provide the native sqlite3 CLI. The targeted regression test was run
with a local compatibility CLI only to exercise the shell/control-flow logic. It is NOT counted as a
substitute for the full native integration suite.

The full suite must be run on the deployment host from the COMPLETE EXTRACTED 30AE RELEASE TREE,
not from /opt/bric2. bric-update is role-safe by design: on a BRIC_ROLE=slurm host it installs cluster
paths but not the complete tape role, and vice versa. A full cross-role suite launched from such an
installed tree produces misleading failures (for example missing tape/bin/bric-tape-import-inventory
or stale cross-role tape scripts). Review 30AE detects this condition up front and exits with an
explicit instruction instead.
