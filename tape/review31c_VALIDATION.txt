- nst1 bsfm repeatability ~0.16%; cross-drive bsfm agreement within ~3%;
- mt tell / MTIOCPOS returned I/O error, so LOCATE/tell/seek is excluded.

Legacy Review30E near miss
--------------------------
A Review30E daemon from an extracted tree survived across later releases because its singleton namespace
predated the current systemd namespace. Follow-up checks found no observed BRIC activity from those PIDs:
no local BRIC event/process log, no QNAP fallback log, no residual chunk_*.CLAIMED, and no open nst device
before termination. Review31C treats the episode as a migration-fencing near miss and closes both directions
of the namespace transition.

Important local limitation
--------------------------
The build container does not provide the native sqlite3 CLI used on supekgate04fl. SQLite-dependent local
checks use a small Python sqlite compatibility shim only for SQL/control-flow coverage. This is not claimed
to be equivalent to the native full release gate. A full-suite attempt was therefore not accepted as a
release result: timeout-sensitive historical tests run far more slowly in this container; a Review31B1
control showed the same delay through reservation and first-chunk completion as Review31C.

Required release gate before installation
-----------------------------------------
Run from a COMPLETE EXTRACTED Review31C release tree on supekgate04fl with native sqlite3:

  sha256sum -c MANIFEST.sha256
  bash test/run_all_tests.sh --timeout 600

Expected selection count: 61 tests.
Do not install Review31C or run real media smoke unless the native suite reports 61 passed, 0 failed.
